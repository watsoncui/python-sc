## 第 3 周 · NumPy 进阶与误差基础

| 节次 | 标题 | 层次 | 说明 |
|------|------|------|------|
| 3.1 | 矩阵分解的调用：LU、QR、SVD 初识 | B | 不推导公式，侧重「何时用哪个、怎么调 scipy/numpy」 |
| 3.2 | 误差、稳定性与条件数 | B | 浮点、相对误差、条件数对线性方程组的影响；与数值分析呼应 |
| 3.3 | 线性方程组（一）：直接法 | B | 高斯消元、LU 分解、scipy.linalg.solve；由 2×2 到 n×n |

**第 3 周 · 每节 45 分钟建议与充实要点**

- **3.1**  
  - *建议分配*：为何需要分解（解方程、稳定性、后续统计）5min → LU：scipy.linalg.lu、L/U 的形态、解 Ax=b 的两步 10min → QR：正交性、scipy.linalg.qr、与最小二乘的预告 8min → SVD 初识：svd、奇异值、与「主方向」的直观 10min → 随堂：对同一矩阵做 lu/qr/svd，观察形状与数值 12min。  
  - *充实要点*：① 不推公式，只讲「输入是什么、输出是什么、典型用途」。② 用 2×2 或 3×3 可手算的例子对照。③ 指出「以后最小二乘会用 QR，降维会用 SVD」。

- **3.2**  
  - *建议分配*：浮点数与机器精度（eps、1+1e-16）、舍入 8min → 相对误差与有效数字 5min → 条件数定义、cond(A) 与 np.linalg.cond 7min → 病态方程组的例子：小扰动导致大误差 10min → 随堂：构造一个条件数很大的 2×2 矩阵，比较「真解」与 solve 得到的解、改右端看变化 15min。  
  - *充实要点*：① 用「线性方程组 Ax=b，b 有误差时解会差多少」贯穿。② 给出 Hilbert 矩阵或自编病态矩阵。③ 与数值分析课中的「稳定性」呼应（若学生已修）。

- **3.3**  
  - *建议分配*：问题表述 Ax=b、唯一解条件 3min → 高斯消元思想（2×2 手算一例）7min → LU 分解即「把 A 写成 L·U，再解 Ly=b、Ux=y」8min → scipy.linalg.solve 的用法、与手算结果对照 10min → 随堂：自编 3×3 或 4×4 题目，用 solve 求解并代入验证 17min。  
  - *充实要点*：① 强调「多数情况不自己写 LU，调 solve 即可」。② 可选：演示 solve 与先 lu 再解两步的等价性。③ 随堂题可包含「无解/无穷多解」的矩阵，让学生看报错或结果含义。

## 第 4 周 · 线性代数数值解

| 节次 | 标题 | 层次 | 说明 |
|------|------|------|------|
| 4.1 | 线性方程组（二）：迭代法思想与 Jacobi / G-S | B | 收敛性概念；用稀疏矩阵做一次实验 |
| 4.2 | 特征值与特征向量：幂法、scipy.linalg.eig | B | 由浅：2×2 手算 → 调用 eig，再看应用（如主成分的动机） |
| 4.3 | 最小二乘与正规方程 | B | 超定方程组、法方程、scipy.linalg.lstsq；**AI**：让 AI 写一段拟合直线并检查是否用 lstsq/是否理解残差 |

**第 4 周 · 每节 45 分钟建议与充实要点**

- **4.1**  
  - *建议分配*：直接法在大规模时的成本、迭代法的动机 5min → Jacobi：拆 A=D+L+U、迭代格式、写出一步 x^(k+1) 10min → Gauss-Seidel 与 Jacobi 的对比 5min → 收敛性（对角占优、谱半径的直观）5min → 用 scipy 或自写循环实现 Jacobi，对 3×3 或 5×5 做迭代、画残差下降 15min → 稀疏矩阵 scipy.sparse 的简单创建与一次求解 5min。  
  - *充实要点*：① 用 2×2 手算 2–3 步迭代看数列变化。② 强调「实际中多用 CG/GMRES，这里先建立迭代思想」。③ 随堂可给一个对角占优矩阵和一个不收敛的矩阵对比。④ 说明稀疏矩阵的典型场景（如离散 PDE 得到的大规模矩阵），与第 11–12 周衔接。

- **4.2**  
  - *建议分配*：特征值/特征向量的定义与几何直观 5min → 2×2 矩阵手算特征值与特征向量一例 10min → 幂法思想：反复乘 A 后方向趋向主特征向量 7min → scipy.linalg.eig、eigvals、复数特征值注意 8min → 应用预告：主成分、稳定性（矩阵幂的范数）5min → 随堂：对给定 2×2/3×3 求特征值并验证 Av=λv 10min。  
  - *充实要点*：① 强调「eig 返回的可能是复数，实矩阵也可能有复特征值」。② 用「矩阵幂 A^k 的增长率」连到主特征值。③ 可选：画 2×2 矩阵作用下单位圆的像，与特征方向对照。④ **可涉及文献**：PyDMD（特征值/SVD 提取时空模态）、ZERNIPAX（NumPy/JAX 矩阵运算），见 `literature.md`。

- **4.3**  
  - *建议分配*：超定方程组「无解」、最小二乘意义（残差平方和最小）8min → 法方程 A'Ax=A'b 的推导与解 7min → scipy.linalg.lstsq 的调用、返回解与残差 8min → 直线拟合 y≈ax+b 作为例子（构造 A 与 b）10min → **AI 环节**：让 AI 写「用 lstsq 拟合直线」，检查是否用正规方程/lstsq、是否画残差图 7min → 随堂：换一组数据或改多项式次数再拟合 5min。  
  - *充实要点*：① 用「三点不共线求直线」讲清超定。② 强调残差 r=b-Ax 与「拟合好坏」的对应。③ AI 生成的代码必须能解释、能改（如改成二次拟合）。④ **可涉及文献**：TRIPs-Py 的 Tikhonov 与最小二乘/正则化、curve_fit 在药理/物理参数估计中的应用，见 `literature.md`。

  - *充实要点*：① 用「已知几个时刻的温度，估计中间时刻」举例。② 强调「节点多、高次多项式不一定更好」。③ 给出 Runge 的经典例子（如 1/(1+x²) 在 [-5,5] 等距节点）。

- **5.3**  
  - *建议分配*：样条动机：分段低次、光滑拼接 5min → 三次样条条件（函数值、一阶二阶连续）8min → scipy.interpolate.CubicSpline 或 interp1d(kind='cubic') 的用法 10min → 与上节多项式插值对比：同一组数据画多项式 vs 样条 10min → 随堂：换数据、改边界条件（若有接口）、比较曲线 12min。

  - *充实要点*：① 不推 PCE 公式，只讲「输入-输出用多项式近似」。② 强调「适合低维随机、光滑依赖」的场景。③ 可选：敏感性指标（谁对结果影响大）一句话带过。

- **13.2**  
  - *建议分配*：为何要导数：优化、灵敏度、梯度下降 5min → 数值微分 vs 符号 vs 自动微分 5min → JAX 安装与 grad(f)(x) 对标量/向量函数 12min → jacfwd、向量值函数的 Jacobi 8min → 随堂：对 f(x)=x'Ax、sin(x) 等求 grad 并手算验证 15min。  
  - *充实要点*：① 强调「写函数，JAX 自动给导数」。② 与 6.3 数值微分对比：无截断误差、对复杂函数可行。③ 为下节「用梯度做参数辨识」铺垫。

- **13.3**  
  - *建议分配*：问题：已知 y(t) 的观测、反推 ODE 参数 θ 8min → 损失 = 观测与模型解的差、需要 ∂损失/∂θ、故需 ODE 解对 θ 可微 7min → 用 JAX 写 ODE 右端、用 diffrax 或 simple 的 odeint 与 grad 组合 15min → 小例子：y'=-θ·y，从「带噪数据」拟合 θ 10min → 随堂：改真值或噪声、看拟合结果 5min。  
  - *充实要点*：① 与 curve_fit 对比：这里「模型」是 ODE 解。② 可选：用 scipy 的数值微分近似 ∂/∂θ 做对比（慢且不准）。③ 为 PINN 做动机铺垫。④ **可涉及文献**：JAX ODE 校准（arXiv:2509.07283）、EV-PINN 参数辨识，见 `literature.md`。
