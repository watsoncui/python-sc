# 每周课程 Notebook 设计说明与缺口清单

在已有 **syllabus**、**18 周周历**（含 45 分钟建议与充实要点）、**literature** 的前提下，要做出「每周课程的 notebook」，还缺少或需要明确以下内容。按「结构 → 内容 → 素材 → 流程」整理，便于逐项补齐后再动手写 `.ipynb`。

---

## 一、距离做每周 notebook 还缺少什么

### 1. 结构层面的约定（目前未统一）

| 缺口 | 说明 | 建议 |
|------|------|------|
| **Notebook 粒度** | 每周一个 `.ipynb`（3 节合在一个文件）还是每节一个 `.ipynb`（54 个文件）？ | 建议**每周一个**：`week01.ipynb` … `week18.ipynb`，用 Markdown 二级标题 `## 1.1 …`、`## 1.2 …`、`## 1.3 …` 分节，便于一次打开整周、也便于按节跑。 |
| **每节在 notebook 里的结构** | 每节对应哪些 cell 类型、顺序？ | 建议固定为：**目标/提纲**（md）→ **概念**（md + 可选小公式）→ **演示代码**（code）→ **随堂练习**（md 题目 + code 空 cell 或提示）→ **小结/作业**（md）。 |
| **统一模板** | 封面、课程信息、目录、环境检查、交作业说明。 | 需要一份 **「周模板」**：第 1 个 cell 为课程名与周次、第 2 个为「本讲目标」、最后可留「课后作业」与「AI 使用说明」占位；第 1 周可多加「环境检查」cell（如 `import numpy`）。 |

### 2. 内容层面的缺口（有要点、无可直接粘贴的素材）

| 缺口 | 说明 | 建议 |
|------|------|------|
| **概念文案** | 周历只有「充实要点」的条目，没有可直接放进 Markdown cell 的 2–3 句话或公式。 | 每节需要 **1–2 段简短概念说明**（可列表），或从「充实要点」反推成「概念 cell」的 bullet；不必长，能支撑 5–10 分钟讲解即可。 |
| **可运行代码片段** | 演示用的小例子（如 2×2 矩阵、一段 solve_ivp、一段 curve_fit）尚未写成可直接复制到 code cell 的脚本。 | 按周整理 **「必做演示代码清单」**：每节 2–5 段短代码（创建数组、解 Ax=b、画图等），保证顺序执行无报错；可先做「最小可运行版」，再在讲课中扩展。 |
| **随堂练习题目与预期输出** | 周历中有「随堂：…」描述，但没有具体题目文字和参考答案或预期结果。 | 每节需要 **题目陈述**（写在 md cell）+ **空 code cell 或给提示**；可选：单独 `solutions/` 下放带答案的 notebook 或答案 cell 折叠。 |
| **AI 环节的固定话术与步骤** | AI 环节只有「用 AI 查…」「让 AI 写…」，没有写进 notebook 的提示词范例和「验证步骤」清单。 | 在标了 **AI** 的节次，增加 **1 个 md cell**：标题「AI 辅助环节」、内容为「任务描述 + 建议提示词 + 验证步骤（运行 → 改参数 → 对照文档/手算）」；学生可照做。 |

### 3. 素材与依赖

| 缺口 | 说明 | 建议 |
|------|------|------|
| **示例数据文件** | 第 1 周 CSV、后续可能用到的数据（如拟合用 x,y、ODE 用时间序列）。 | 建目录 **`data/`**，至少提供：`data/week01_sample.csv`（两列 x,y，若干行）；其余可按周补充（如 `data/week06_fit.csv`）。 |
| **环境与依赖列表** | 课程用 uv/conda，但尚未有「notebook 专用」的 environment 或 requirements。 | 在项目根目录提供 **`environment.yml`**（conda）或 **`pyproject.toml`**（uv），包含：Python 3.x、jupyter、numpy、scipy、matplotlib；后续周用到再加 jax、torch 等。 |
| **运行顺序与依赖** | 若某周依赖前面某周的变量或函数（如自定义的 `euler`），未声明。 | 在周模板或该周开头加一句「本讲假设已运行过 weekXX 的 XX 部分」；或关键依赖集中在「第 1 周 + 当周」可重放的最小集合。 |

### 4. 流程与维护

| 缺口 | 说明 | 建议 |
|------|------|------|
| **从周历到 notebook 的映射表** | 写 notebook 时需快速查「这一节要写哪些概念、哪些代码、哪道题」。 | 在本文档或单独 **`notebook-checklist.md`** 中，按周列出：每节「概念条目」「演示代码清单」「练习题目」「AI 话术/步骤」；与 `schedule-18weeks.md` 一一对应。 |
| **作业与答案策略** | 课后作业是否嵌在当周 notebook 末尾、是否单独文件、答案是否公开。 | 约定：每周最后一节留 **「课后作业」** md cell + 可选空 code cell；答案另存或折叠，避免直接抄。 |
| **版本与可复现** | notebook 的 kernel、输出是否提交、如何避免路径问题。 | 约定：提交时 **清除输出** 或 **带输出** 二选一；数据路径用相对路径 `data/...`，并在模板中说明「请将 notebook 放在项目根目录或调整路径」。 |

## 二、Notebook 结构规范（建议）

### 每周一个文件

- 文件名：`week01.ipynb` … `week18.ipynb`（或 `week_01.ipynb` 等，统一即可）。
- 存放：`notebooks/week01.ipynb` 或 根目录 `notebooks/` 下。

### 每节（如 1.1、1.2、1.3）内部结构

每个「节」在 notebook 里占一组连续 cell，建议顺序：

1. **【Markdown】本节目标 / 提纲**（1 个 cell）  
   - 2–4 条 bullet，对应周历里该节的「说明」或「建议分配」的前几条。

2. **【Markdown】概念**（1 个 cell，可选拆成 2 个）  
   - 简短文字 + 必要时行内公式（如 \(Ax=b\)、\(y_{n+1}=y_n+h f(t_n,y_n)\)）。

3. **【Code】演示**（若干 cell）  
   - 可直接运行的最小示例；复杂时 2–3 个 code cell，避免一个 cell 过长。

4. **【Markdown】随堂练习**（1 个 cell）  
   - 题目叙述（编号 1、2、3…）。

5. **【Code】练习**（空 cell 或带 `# TODO` 提示，每个题目一个或共用一个）。

6. **【Markdown】小结 / 课后作业**（1 个 cell，可放在整节末尾或整周末尾）  
   - 若该节有 **AI**，在此前插入 **【Markdown】AI 辅助环节**（任务 + 建议提示词 + 验证步骤）。

### 每周开头与结尾（可选但推荐）

- **第一个 cell（Markdown）**：课程名、第 X 周、本周 3 节标题。
- **第二个 cell（Code，仅第 1 周或每周）**：环境检查，如 `import numpy, scipy, matplotlib`，并 `print("OK")`。
- **最后一个 cell（Markdown）**：本周课后作业汇总、AI 使用说明（若本周有）、延伸阅读（若本周有文献）。

## 五、总结：补齐后即可开始写每周 notebook

| 序号 | 缺少项 | 补齐方式 |
|------|--------|----------|
| 1 | Notebook 粒度与每节 cell 结构 | 采用「每周 1 个 .ipynb + 每节 6 类 cell」规范（见第二节）。 |
| 2 | 概念文案 | 从周历「充实要点」逐节写出 1–2 段或 bullet，放入 md cell。 |
| 3 | 演示代码 | 按周历「建议分配」与「充实要点」整理每节 2–5 段可运行代码，按节放入 code cell。 |
| 4 | 随堂练习题目与 code 占位 | 把周历「随堂：…」写成具体题目 + 空 cell 或 TODO。 |
| 5 | AI 环节话术与验证步骤 | 在标 AI 的节增加 1 个 md cell（任务+提示词+验证）。 |
| 6 | 示例数据与环境文件 | 建 `data/`、至少 `week01_sample.csv`；写 `environment.yml` 或 `pyproject.toml`。 |
| 7 | 周模板与目录 | 建 `notebooks/`、`notebooks/README.md`、`week01.ipynb` 模板（或第 1 周完整版）。 |
| 8 | 按周内容清单（可选但推荐） | 做 `notebook-checklist.md` 或在本文件第三节扩展成全 18 周表格，写 notebook 时打勾。 |

以上都明确或补齐后，即可按「周 → 节 → 概念 / 代码 / 练习 / AI」顺序批量编写每周 notebook。
