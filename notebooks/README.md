# Notebooks

Weekly Jupyter Notebook lectures for the Python Scientific Computing course.

## Usage

1. Make sure the environment is set up: `uv sync` (from the repo root).
2. Start JupyterLab: `uv run jupyter lab`
3. Open any `weekXX.ipynb` file.

## Conventions

- One notebook per week: `week01.ipynb` … `week18.ipynb`
- Data files are in `../data/` (relative to this directory)
- See `../meta_course/notebook-design.md` for the full structure spec
